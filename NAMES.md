# Name brainstorm

Fifteen candidate names for the project, each screened for existing use. Screening done October 30, 2026.

## Read this first

- **The current placeholder, "Loci", is already taken by a math visualization app.** Iverton Darlan and Dan Reznik's *Loci* is a browser app for visualizing loci in Poncelet triangle geometry, with a published paper and a GitHub repository. That's the same field as this project, so "Loci" should be replaced before anything is public.
- **The legal risk with a name is trademark, not copyright.** Names and short phrases generally can't be copyrighted. They can be trademarks, and the risk is confusion with an existing mark in a similar field (software, education, mathematics).
- **This is a screen, not a clearance.** For each name I searched the web for existing products, companies and apps, and checked whether the `.com` and `.org` domains are registered. That catches obvious collisions only. Before committing, do the checks in the last section.

### Shortlist

- **Lemniscroll.** Most distinctive, and it describes the product: a scroll that never ends, named after the curve that never ends. Both domains free.
- **Curvarium.** Easiest for non-mathematicians to say and remember. Both domains free.
- **Theoremscope.** Clear meaning, sounds established, both domains free. It's long for a logo.

For names 10–15, a registered `.com` doesn't necessarily mean a conflict; it may be parked. Look at what's there before ruling one in or out, and expect to use `.org` or another domain.

## Before choosing a name

1. **Trademark databases.** Search the USPTO trademark search system (and EUIPO / WIPO's Global Brand Database if you'll be international) for exact and similar spellings in classes 9 (software), 41 (education) and 42 (online services).
2. **Platforms.** Check that the GitHub organization name, npm package scope, App Store and Play Store names, and social handles are free.
3. **Say it out loud.** Check that people can spell it after hearing it once, and that it doesn't mean something unfortunate in the languages your audience speaks.
4. **Ask a lawyer** if you'll invest in branding, or form an organization around the name. A trademark attorney's clearance search costs far less than a forced rename later.
5. **Register the domains** for the winner as soon as you decide. Unregistered names can be taken at any time.
